# Mox

Downloads for Mox, a Mac app for photographic 3D book mockups.

Get the latest version from [Releases](../../releases/latest): download the `.zip`, unzip it and drag **Mox** into Applications. Mox checks here for updates when it opens.

Requires a Mac with Apple silicon (M1 or later) and macOS 14 Sonoma or newer.

**First launch:** Mox isn't notarised by Apple yet, so macOS will refuse to open it the first time. Click Done, then open System Settings → Privacy & Security and choose **Open Anyway** next to Mox.
